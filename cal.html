``` --- ### 2. `manifest.json` ```json { "short_name": "Calc&Convert", "name": "Calculator & Converter PWA", "description": "A web app for various calculations and conversions.", "start_url": "/", "display": "standalone", "background_color": "#ffffff", "theme_color": "#007bff", "orientation": "any", "icons": [ { "src": "/icons/icon-192x192.png", "type": "image/png", "sizes": "192x192" }, { "src": "/icons/icon-512x512.png", "type": "image/png", "sizes": "512x512" } ] } ``` **หมายเหตุ:** คุณต้องสร้างโฟลเดอร์ `icons` และใส่ไฟล์ `icon-192x192.png` และ `icon-512x512.png` เข้าไป --- ### 3. `sw.js` ```javascript // Cache name const CACHE_NAME = 'calc-convert-pwa-v1'; // Changed name for PWA version // Files to cache. IMPORTANT: Add ALL files needed for offline use. // If you have a separate JS file (e.g., app.js), add it here. const urlsToCache = [ '/', // The root URL loads index.html '/index.html', // Explicitly cache index.html '/manifest.json', // PWA manifest '/icons/icon-192x192.png', // App icon '/icons/icon-512x512.png', // Add any other essential assets like fonts, specific JS/CSS files if not inlined. // For this example, all JS/CSS is inlined in index.html, so no extra assets needed here. ]; // --- Installation Event --- self.addEventListener('install', (event) => { // Perform install steps event.waitUntil( caches.open(CACHE_NAME) .then((cache) => { console.log('[Service Worker] Opened cache'); return cache.addAll(urlsToCache); // Cache all the essential files }) .then(() => self.skipWaiting()) // Skip the waiting lifecycle and activate immediately ); }); // --- Activation Event --- self.addEventListener('activate', (event) => { // Remove outdated caches event.waitUntil( caches.keys().then((cacheNames) => { return Promise.all( cacheNames.map((cacheName) => { if (cacheName !== CACHE_NAME) { console.log('[Service Worker] Deleting old cache:', cacheName); return caches.delete(cacheName); } }) ); }) .then(() => self.clients.claim()) // Make this service worker control all clients (tabs/windows) ); }); // --- Fetch Event --- self.addEventListener('fetch', (event) => { event.respondWith( // Try to match the request in the cache first caches.match(event.request) .then((response) => { // If found in cache, return it if (response) { return response; } // If not found, fetch from the network return fetch(event.request).then( (response) => { // If the request was successful, cache the new response. // We only cache GET requests that are successful and not for service worker script itself. if (response && response.status === 200 && event.request.method === 'GET' && !event.request.url.endsWith('.js')) { const responseClone = response.clone(); caches.open(CACHE_NAME) .then((cache) => { cache.put(event.request, responseClone); }); } return response; } ).catch(() => { // If both cache and network fail, return a fallback response. // You might want to create a dedicated offline.html page. console.log('[Service Worker] Fetch failed and no cache fallback available for:', event.request.url); // For simplicity, return a text response. In a real app, return an offline page. return new Response('คุณออฟไลน์อยู่', { headers: { 'Content-Type': 'text/plain' } }); }); }) ); }); ``` --- ### การใช้งาน: 1. **สร้างโฟลเดอร์ `icons`**: สร้างโฟลเดอร์ชื่อ `icons` ใน Root Directory. 2. **เตรียม Icon**: หาไฟล์รูปภาพ 2 ไฟล์: * `icon-192x192.png` * `icon-512x512.png` แล้วนำไปวางไว้ในโฟลเดอร์ `icons` 3. **บันทึกไฟล์**: * บันทึกโค้ด HTML เป็น `index.html` * บันทึกโค้ด JSON เป็น `manifest.json` * บันทึกโค้ด JavaScript เป็น `sw.js` * วางไฟล์ทั้งหมดนี้ไว้ใน Root Directory เดียวกัน (ยกเว้นโฟลเดอร์ `icons`) 4. **Serve ไฟล์**: **สำคัญมาก**: ไฟล์ PWA (โดยเฉพาะ Service Worker) จะต้องถูก Serve ผ่าน HTTPS หรือ Localhost ที่ตั้งค่าให้รองรับ Service Worker ได้ (เช่น ใช้ Live Server ของ VS Code หรือ npm package `http-server`). การเปิดไฟล์ `index.html` โดยตรงจาก File System (`file:///...`) จะไม่สามารถลงทะเบียน Service Worker ได้. 5. **ทดสอบ**: เปิดแอปผ่าน Localhost (เช่น `http://localhost:8000`) หรือ Server ของคุณ, เปิด Developer Tools (F12), ไปที่แท็บ Application เพื่อดูสถานะ PWA. หากใช้งานแล้วจะมี Option ให้ "Install App" บน Browser. โค้ดชุดนี้เป็นชุดที่สมบูรณ์และพร้อมใช้งานครับ!
